## 1. Core Farming System

### 1.1 Soil & Plots
- [ ] 1.1.1 Farm spawns on zone enter (Valley of Four Winds, zone 1023)
- [ ] 1.1.2 Farm despawns on zone leave
- [ ] 1.1.3 Starts with 4 soil plots (phased per-player)
- [ ] 1.1.4 Expands to 16 plots via Union questline
- [ ] 1.1.5 Each plot is per-player phased instance
- [ ] 1.1.6 Soil states: Empty → Prepared → Seeded → Growing → Ready → Harvested
- [ ] 1.1.7 Plot states: Occupied (Virmen), Stubborn (weed) between harvest and till

### 1.2 Tilling
- [ ] 1.2.1 Click soil to till one plot
- [ ] 1.2.2 Handle Occupied soil (kill Virmen)
- [ ] 1.2.3 Handle Stubborn soil (Pull ability minigame)
- [ ] 1.2.4 Earth-Slasher Master Plow tills 4 plots in a row (Exalted unlock)

### 1.3 Planting
- [ ] 1.3.1 Click tilled soil, then click seed to plant
- [ ] 1.3.2 Seed bags plant 4 plots at once (2x2 area)
- [ ] 1.3.3 Bursting crops appear immediately after planting (harvest same day)
- [ ] 1.3.4 Dented Shovel removes crop (seed lost, plot cleared)

### 1.4 Tending (8 crop problems)
- [ ] 1.4.1 Alluring — defend against Plainshawk (hostile mob spawns)
- [ ] 1.4.2 Infested — use Vintage Bug Sprayer (item 80513)
- [ ] 1.4.3 Parched — use Rusty Watering Can (item 79104)
- [ ] 1.4.4 Runty — interact then Jump (spacebar)
- [ ] 1.4.5 Smothered — interact then Pull ability (spam 1)
- [ ] 1.4.6 Tangled — grab tanglevine, run 15+ yards away
- [ ] 1.4.7 Wiggling — defend against Virmen (hostile mob spawns)
- [ ] 1.4.8 Wild — Flex ability (spam 1 for 50 Dominance stacks), Gnaw to interrupt Vine Slam

### 1.5 Harvesting
- [ ] 1.5.1 Click ripe crop to harvest
- [ ] 1.5.2 Ripe crops yield 5 vegetables
- [ ] 1.5.3 Plump crops yield 8 vegetables (rare random)
- [ ] 1.5.4 Bursting crops yield 5 (or 7 on bonus day), harvestable immediately
- [ ] 1.5.5 Bonus crop day yields 7 (or 10 for Plump)
- [ ] 1.5.6 Harvest yields seeds of same type (0-3 extra)
- [ ] 1.5.7 Very rare: Ominous Seed drop
- [ ] 1.5.8 Rare: gift items drop (for friendship)
- [ ] 1.5.9 Rare: Paper-Covered Rock (Brawler's Guild)
- [ ] 1.5.10 50 Tillers rep per harvest at level 90 (none below 90)

### 1.6 Growth Timer
- [ ] 1.6.1 Crops mature at next daily reset (~03:00 server time)
- [ ] 1.6.2 Growing buff shows time remaining on crop tooltip
- [ ] 1.6.3 Unharvested crops persist across days
