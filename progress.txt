KEY DISCOVERIES
---------------
- EK zones initially appeared to have 0 type-8 critters (wrong JOIN); they actually have hundreds of critter spawns
- Most pets in Arathi, NST, Cape use type-8 with matching critter names
- Deadwind Pass has NO type-8 critters whatsoever — type-14 only
- BattlePetSpecies.db2 (WDB2 format, 845 records, 9 fields, 36 bytes/record):
    field[0]=hash (not species ID), field[1]=flags, field[4]=minLevel (pet battle),
    field[5]=description string, field[6]=zone/location string,
    field[7]=species ID (primary key), field[8]=creature ID (type-14 NPC FK)
  - String table starts at offset 20+records*record_size; strings are null-terminated
  - Field[6] zone refs are often truncated due to shared string table (preceding string overlaps)
- Type-14 NPCs (entry >= 61080) are stored in creature_template with type=14
- All 845 species records in BattlePetSpecies.db2 verified readable
